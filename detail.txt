2. FRONTEND ARCHITECTURE & FRAMEWORK
------------------------------------------------------------------------------
- Core Framework: React 18+ Single Page Application (SPA) with Vite 5.x bundling.
- Routing Architecture: Custom client-side dynamic route state parser:
  * Storefront Homepage: '/'
  * Dedicated Dynamic Product Detail Pages: '/product/:id' (with deep-link support)
  * Founder Admin Portal: '/pass' or '/admin' (with secure session auth)
  * Policy Modals: Integrated overlay viewer for Privacy, Terms, Shipping, Returns.
- Micro-Interactions & Animation:
  * Canvas-Confetti on successful COD order placement.
  * Shimmer gold badges and smooth hover elevation cards.
  * Auto-rotating 2-second social proof testimonial carousel.
  * Live Sales Notification Toaster (simulates authentic Pakistani city purchases).
- Icons & Visual Assets: Lucide React icon suite + Custom SVG brand vector assets.
- Responsive Design: 100% fluid mobile-first architecture optimized for 4G/3G
  smartphones, tablets, and 4K ultra-wide monitors.

3. BACKEND, CLOUD DATABASE & REALTIME SYNC
------------------------------------------------------------------------------
- Cloud Database: Google Firebase Cloud Firestore (Enterprise rules configured).
- Local State Resilience: Dual-layer persistence architecture:
  * Layer 1 (Cloud): Remote Firestore collections ('orders', 'visitors', 'settings').
  * Layer 2 (Local): Browser localStorage synchronization ensures instant offline
    resilience and zero checkout drops even on fluctuating 3G/4G Pakistani networks.
- Analytics & Visitor Tracking:
  * Live hit recording per route ('/' and individual '/product/:id' watch pages).
  * Real-time visitor counters showing realistic live viewers (11–24 concurrent).
- Founder Admin Bridge (`/pass`):
  * Real-time order management dashboard.
  * One-tap WhatsApp confirmation dispatch link generator.
  * Order status management: Pending Verification, Confirmed, Dispatched, Delivered.
  * CSV export engine for courier booking (Trax, PostEx, TCS, Leopards).
